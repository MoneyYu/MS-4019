# MS-4019 Reference
> ##### **Course MS-4019-A: Transform your everyday business processes with agents**: <br/> A one-day, **no-code** course for everyday business users. Learn what **agents** are, use the **prebuilt agents** in Microsoft 365 Copilot Chat (Analyst, Researcher, Prompt Coach, Idea Coach, Writing Coach), **build and manage** your own agents with **Agent Builder** (in Copilot Chat) and the **SharePoint** agent tool, then **share and use** them across Teams and Microsoft 365 — all without writing code.

```markmap
# Transform your everyday business processes with agents (MS-4019)

## Foundations
- [What is Microsoft 365 Copilot?](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-overview)
- [How it works](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-architecture): grounding via **Microsoft Graph**
- [Data, privacy & security](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-365-copilot-privacy)
- [Agents for Microsoft 365 Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/agents-overview) = instructions + knowledge + (capabilities)
- No-code, for everyday business users

## M01 - Get started with agents
### What agents are & access
- Embedded AI assistants in **Copilot Chat** & **SharePoint**
- [Copilot Chat](https://learn.microsoft.com/en-us/copilot/overview) (web grounding, included) **vs** [full Microsoft 365 Copilot](https://learn.microsoft.com/en-us/microsoft-365/copilot/which-copilot-for-your-organization) (work/Graph grounding, licensed)
- Work-data agents need [pay-as-you-go / Copilot Credits](https://learn.microsoft.com/en-us/microsoft-365/copilot/pay-as-you-go/overview) or a Copilot license
- SharePoint agent [access & permissions](https://learn.microsoft.com/en-us/sharepoint/manage-access-agents-in-sharepoint): Edit to create, Read to use
### Benefits & governance
- Task simplification, better search, collaboration, personalization
- [Copilot Control System](https://learn.microsoft.com/en-us/microsoft-365/copilot/copilot-control-system/overview): organization owns IT governance

## M02 - Explore prebuilt agents
- [Agents built by Microsoft](https://support.microsoft.com/en-us/Microsoft-365-Copilot/agents-built-by-microsoft) — ready to use, no setup
- [Analyst](https://support.microsoft.com/en-us/Microsoft-365-Copilot/get-started-with-analyst-in-microsoft-365-copilot): analyze data, runs Python
- [Researcher](https://support.microsoft.com/en-us/Microsoft-365-Copilot/get-started-with-researcher-in-microsoft-365-copilot): deep, cited research
- Prompt Coach / Idea Coach / Writing Coach
- **Labs**: Analyst, Researcher, agent of your choice

## M03 - Build and manage an agent
### Tools (no code)
- [Agent Builder](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/agent-builder) in Copilot Chat **vs** [SharePoint](https://support.microsoft.com/en-us/SharePoint/copilot-in-sharepoint/create-an-agent-in-sharepoint) agent tool
- [Describe vs Configure](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/agent-builder-build-agents); Code interpreter & Image generator (Agent Builder only)
### Components & manage
- Name, description, instructions, knowledge sources, starter prompts
- Test, edit, [manage agents](https://support.microsoft.com/en-us/SharePoint/copilot-in-sharepoint/manage-agents-in-sharepoint)
- **Labs**: create a Copilot Chat agent & a SharePoint agent (Fabrikam simulation)

## M04 - Share and use agents
- [Share from Copilot Chat](https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/agent-builder-share-manage-agents): anyone / specific users / only you
- SharePoint: site members with **Edit** can create/edit/share; the site owner sets the site's **main agent**; [share in Teams](https://support.microsoft.com/en-us/SharePoint/copilot-in-sharepoint/share-an-agent-from-sharepoint-in-teams) via @mention
- Sharing an agent ≠ granting data permissions (permission-trimmed)
- [Interact with agents](https://support.microsoft.com/en-us/SharePoint/copilot-in-sharepoint/interact-with-agents-in-sharepoint): permission-trimmed answers, hub-site knowledge, private chat history
```
