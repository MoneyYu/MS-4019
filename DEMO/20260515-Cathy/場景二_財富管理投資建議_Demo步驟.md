## 場景背景（30 秒講師開場）

> 「Q3 投資觀點月報週五就要對外發送，但 Joni 對自己的『美債加碼 +2』觀點動搖 — Fed 5 月鮑威爾偏鷹，但 4/30 公布的核心 PCE 比預期低，到底要不要加碼？
>
> 同時，世華私行有 200 多位 VIP 客戶等著看月報，每位客戶風險屬性、AUM、組合都不同。Joni 的觀點是『集團觀點』，但每位客戶需要的是『客製化建議』。
>
> 這個矛盾正是 Researcher + Analyst Agent 的最佳發揮場景。」

## Demo 5 步驟

### Step 1：Researcher Agent — 整合最新 Fed 觀點（6 min）

打開 M365 Copilot，切換到 **Researcher Agent**，輸入：

```
我（admin）正在協助 Joni Sherman（國泰投信）與 Isaiah Langer（國泰世華）準備 2026 Q3 投資觀點客戶月報，但 Joni 對「美債（長天期）加碼」這個觀點有疑慮。

請整合以下資訊：
1. OneDrive 中「S2_2026Q3全球市場展望.docx」Joni 的初稿觀點
2. 公開網路最新資料：Fed 主席 Jerome Powell 2026 年 5 月最新公開談話對降息路徑的暗示
3. 4/30 公布的核心 PCE 數據與市場反應
4. BofA Fund Manager Survey 對全球資金流向的最新反映
5. 同業（中信、富邦、永豐）4 月私行月報的差異觀點

最後請給 Joni 三句總結，讓她可以拿到週五前定稿會討論：
- 美債加碼仍合適 vs. 應降為中性的論點
- 客戶月報建議措辭
- 風險點
```

**預期成果**：Researcher 整合 Word 草稿 + 公開最新 Fed 資料 + 同業觀點，給出措辭建議（呼應 email thread 中 Isaiah 提的「逢回布局」論點）。

---

### Step 2：Analyst Agent — VIP 客戶組合績效歸因（8 min）

切換到 **Analyst Agent**，附上 `S2_全球市場原始資料.xlsx` + `S2_組合績效Dashboard.xlsx`，輸入：

```
請基於這兩個檔案：

1. 從「客戶組合明細」分頁找出 5 位 VIP 客戶（VIP-2024-08321 等）
2. 計算每位客戶 Q1 投資組合的 Brinson 法歸因（資產配置效應 vs. 證券選擇效應）
3. 找出哪位客戶受惠最大、哪位最受影響
4. 對比每位客戶與其風險屬性的目標配置，列出偏離 ≥3pp 的項目
5. 給每位客戶一段 80 字的「下季再平衡建議」

重點：RR4 客戶（VIP-2024-08321）的波動率已達 11.8%（目標上限 13%），請特別標示風險警示。
```

**預期成果**：Analyst 跑 5 位客戶完整歸因、找出 RR4 客戶風險偏高、產出可直接用於客戶月報的客製化建議。

---

### Step 3：用 Copilot 升級客戶月報半成品 PPT（8 min）

打開 `S2_2026Q3市場展望_半成品.pptx`：

```
這是 Q3 客戶月報草稿，請依序：

1. 第 1 頁宏觀環境：補上 Fed / ECB / BOJ / 中國 / AI 主題的最新政策利率與市場共識（用 Researcher Agent 剛才整合的內容）
2. 第 2 頁區域配置矩陣：基於「全球市場原始資料.xlsx」產出 8 大資產類別配置表（含上月對比）
3. 第 3 頁客戶組合績效歸因：用 Analyst Agent 剛才的 Brinson 結果產出摘要圖
4. 第 4 頁下季三大行動：整合本月觀點 + RR4 客戶風險屬性，提出 3 個具體再平衡建議

注意：美債措辭請用「逢回布局」而非「加碼 +2」。
```

**預期成果**：半成品 PPT 在 8 分鐘內升級為包含個別客戶歸因的客製化月報。

---

### Step 4：跨子公司協作 — 串接世華 Analyst Agent（5 min）

**情境**：世華私行已導入「Analyst Agent + 客戶 360」整合機制（Isaiah 在 email 提到的試點），下個月起客戶月報會自動結合每位 VIP 客戶的客製化解讀。

打開 Copilot Chat：

```
請用 Analyst Agent 整合以下三件事：
1. 世華私行 VIP-2024-08321 的客戶 360 view
2. 國泰投信 Q3 觀點月報（剛才升級完的版本）
3. 風險管理處的壓力測試結果

產出一份「給 VIP-2024-08321 的個人化版本」客戶月報，包含：
- 本月觀點對你組合的影響
- Q1 績效歸因（你的組合 vs 整體 Q3 觀點）
- 下季三大行動建議（針對你的 RR4 風險屬性客製化）
- 壓力測試情境下你組合的可能損益
```

**預期成果**：跨子公司 Agent 整合 demo，呈現「集團觀點 → 客戶級別 → 個人化建議」的能力。

---

### Step 5：對比與結語（3 min）

打開 `S2_2026Q3市場展望_完整版.pptx` 對比剛升級後的版本。

**講師結語**：

>
> 用 Researcher + Analyst + 跨子公司 Agent 串接，**集團觀點生成（30 分鐘）+ 200 個客戶版本（自動化）**。

## 學員 Q&A 提示

| 學員可能問 | 講師可回答 |
|---|---|
| Researcher 整合的「最新 Fed 談話」可信嗎？ | Researcher 會標出處，但使用者要 review，特別是金融重大決策 |
| 200 位客戶都自動產月報，會不會出錯誤建議？ | 會標示「AI 輔助生成、客戶經理審核確認」，符合 4/22 AI 治理新規「人類覆核」要求 |
| 客戶資料如何保護？ | Analyst Agent 在 tenant 內運算，資料不離開 M365 boundary，個資規範符合 |
| 美債觀點 5 月前後變化大，月度更新夠嗎？ | 可以建立「市場觀點」SharePoint Agent 即時更新，這是 Module 3 內容 |
