## 2. ⚠️ Demo 帳號使用規則（鐵律）

**全程只用 admin@moneyyu.com 登入**，所有 demo 操作（M365 Copilot、SharePoint、OneDrive、Teams、Outlook、Calendar）一律從這個帳號出發。

| 動作 | 用哪個帳號？ |
|---|---|
| 講師現場 demo 登入 | **admin@moneyyu.com** |
| 開啟 OneDrive、Outlook、Calendar、Teams、SharePoint | **admin@moneyyu.com** |
| 在 Copilot Chat 跑 Researcher / Analyst Agent | **admin@moneyyu.com** |
| 建立 SharePoint Agent 或 Copilot Chat Agent | **admin@moneyyu.com** |
| 分享 Agent 給其他角色 | **僅展示 UI，不實際送出** |

**步驟書中的 prompt 寫法**：
- ❌ 錯誤：「我是 Christie 的視角...」（這要求登入 ChristieC，但講師沒有密碼）
- ✅ 正確：「我（admin）正在協助 Christie 準備...」（admin 視角，實際操作可行）

**例外**：場景五 Module 4「Share & Use」演示時，prompt 內可寫「我是 Joni（投信）...」，但這是 **prompt 內的角色聲明**（給 Agent 判斷視角），實際登入仍是 admin。

## 7. 講師備忘

### 7.1 「半成品 PPT」雙軌策略

每場景有 `_完整版.pptx` 與 `_半成品.pptx` 兩種：

- **半成品**：給 Demo 現場用 Copilot 升級，戲劇效果強
- **完整版**：給學員看「目標長相」，下半場可拿來對照

建議流程：先打開 `_半成品.pptx` → 用 Copilot 升級 → 跟 `_完整版.pptx` 對比 → 學員看到 Agent 帶來的轉變。

### 7.2 重跑時間軸

每次重跑 `run.ps1`：
- Calendar events 與 Meeting chats 會用**當下日期**重新計算 dayOffset
- Email、Teams 訊息**不會重複建立**（首次執行後再執行會出現重複，要手動清理）
- **Phase 7 SharePoint** 全 idempotent，重跑會跳過已存在的 site / list / item

> **建議**：5/15 課前 1 天執行 `.\run.ps1`，吃下兩個成本：(1) 重新對齊 dayOffset；(2) 給 Copilot 4-24 hr 索引時間。

### 7.3 Researcher / Analyst Agent 啟用方式

- **Researcher Agent**：M365 Copilot Chat 左側 Agent 面板選「Researcher」
- **Analyst Agent**：同左側面板選「Analyst」
- 若學員 tenant 沒看到，請先確認 M365 Copilot 授權與 Agent feature flag 已啟用

### 7.4 場景六 vs 場景三/四/五 對比口訣

| 維度 | 場景六（Copilot Chat Agent）| 場景三/四/五（SharePoint Agent）|
|---|---|---|
| 建立位置 | Copilot Chat 左側 + | SharePoint 文件庫 + Add agent |
| 知識源 | 自選（含跨來源）| 自動 = 該 site |
| Starter Prompts | **必填**（教學員寫好 prompt）| 自動生成 |
| 適合場景 | 跨來源、流程化、業務用 | 文件集中、團隊共用 |
| 官方時長 | **36 min（份量更大）** | 26 min |
| 課程時段 | 13:30-14:00（Module 3a）| 14:00-15:00（Module 3b）+ 場景五（M4） |

### 7.5 課後練習建議

- 每位學員回到自己工作崗位後，至少嘗試把一個既有月報流程 Agent 化
- 60 天回訪：彙整集團內 Agent 使用案例
